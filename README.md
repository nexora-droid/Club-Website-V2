# Hack Club NOVA Website Version 2

This is a project made by Ashlesh & Shaurya for Thirdspace @ Hack Club.

## What is this project about?
This project is a full-stack website that combines frontend and backend logic to make a dynamic website, for both members and external visitors.
Following languages were used in the building of this website:
1. Frontend Lanuages:
    1. HTML (Hyper Text Markup Language)
    2. CSS (Cascading Style Sheet)
    3. JS (JavaScript)
  2. Backend Lanuages:
    1. Express JS 
    2. Node JS 

## Features
- Contacting admins through website
  - Scroll down on the main page, till you see a contact form with three fields: Subject, Email and Message.
  - Fill in these fields and then click send message.
  - A new ticket is made in our system, and we are notified.
  - A response to your ticket will be made within 2-3 business days! (yes business days lol.... maybe like 10 realistically....hehehe)
- Admin Panel
  - Adding announcements
  - Adding new projects to specific users
  - Adding new events
  - Adding new meetings
  - Checking member information such as name, email and specific projects
  - Messaging members directly through website. (1-way only)
- Member Panel
  - Viewing upcoming meeting
  - Viewing last 2 projects made by you
  - Viewing active events
  - Profile management:
    - Password changing
    - PFP changing
    - Logging out
    - Changing notification preferences
  - Notifications about chosen preferences (new announcement, project or event)
  - Default meeting notification
- 404 Page (its a feature oh yes)
  - Game on 404 page, with flying powerup, and more fun powerups
