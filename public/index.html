Boba Drops

Beginner Website Design Workshop

Boba Drops is a Hack Club program where our members built personal websites and were rewarded with a grant to buy boba. The workshop was run by our president Ashlesh and our head of web dev Shaurya. Our members built their own personal website using HTML & CSS, hosted it on GitHub Pages, and submited it to the program. Each approved submission earnt them $5 for boba.
